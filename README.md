# 첫걸음

보고서 작성에 집중한 규칙 기반 시제품입니다. 계정·외부 AI·서버 DB 없이 동작합니다.

## 실행

Node.js로 `node server.mjs` 실행 후 http://localhost:4173 에 접속하세요.
테스트: `node --test *.test.mjs`

## 구조

- dist/rules.mjs: 진행 상태와 행동 크기에 따른 규칙. UI와 독립적으로 검증합니다.
- dist/app.mjs: 해시 기반 화면 이동, 입력 처리, 로컬 저장소, 선택형 타이머.
- dist/style.css: 반응형 화면. 주요 화면의 공통 헤더·하단에서 지원 안내에 접근합니다.
- 데이터: tasks(과제·마감·단계·행동 크기·중단 상태), logs(행동·결과·난이도·메모·시각).

## 범위와 한계

브라우저 localStorage에만 저장되며 기기 간 동기화되지 않습니다. 타이머는 새로고침 시 초기화되고 행동은 보존됩니다. 과제 단계는 사용자가 직접 변경합니다. 모든 보고서의 전체 작업을 자동 추정하지 않고, 현재 단계에서 실행할 다음 행동을 제안합니다. 진단·치료·위험도 판단·선별검사 기능이 없습니다.

## 4주 활용 계획

1주: 현재 흐름을 직접 시연하고 추천 규칙 검토.
2주: 동료 사용자 3~5명과 사용성 확인 후 표현과 규칙 수정.
3주: 접근성·모바일 점검 및 시연 자료 준비.
4주: 발표 리허설, 로컬 실행과 배포본 준비.

시연: 과제 입력 → 2분 행동 → 어렵다/크게 느껴진다 → 재분할 → 쉽다/증가 → 일부 진행 기록 → 기록 조회 → 다시 시작 → 중단 → 이어서 하기.
